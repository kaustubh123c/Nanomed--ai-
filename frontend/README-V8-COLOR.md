# NanoMed-AI Frontend v8 — Clinical Ocean Theme

Frontend-only visual update based on v7.

- Strong Clinical Ocean palette: deep blue + teal + cyan
- Deterministic CSS overrides so old Tailwind color aliases do not hide the new theme
- Redesigned sidebar/topbar/card surfaces
- Existing v7 features retained
- Backend untouched

Run:
`npm install`
`npm run dev`

If the browser still shows an older theme, use Ctrl+Shift+R or clear the Vite/browser cache.
